ownCloud upgrade failed.
=======================

The package is installed, but the database upgrade did not complete and
ownCloud is in maintenance mode.

A full pre-upgrade backup was created before the upgrade:

  @FULL_BACKUP@

The ownCloud data directory was not modified.

To roll back to the earlier version:
1. The backup is on the data share and survives uninstalling the package.
   Copy it somewhere safe if you want to keep it.
2. Uninstall ownCloud from Package Center, keeping the data share.
3. Install owncloud @OLD_PKGVER@ and choose to restore from a backup; select
   the backup file above. The package restores the configuration, apps and
   database, and re-applies the previous PHP/WebStation profile.
4. If you customized .htaccess or .user.ini, re-apply them from configs/root
   inside the backup archive.
