ownCloud upgrade failed.
=======================

A full pre-upgrade backup was created before the upgrade:

  @FULL_BACKUP@

The ownCloud data directory was not modified.

Option 1 - retry the upgrade (preferred)
----------------------------------------
Most failures can be fixed and retried on the new tree:

  sudo -u sc-owncloud /usr/local/bin/php83 /var/services/web_packages/owncloud/occ maintenance:mode --off
  sudo -u sc-owncloud /usr/local/bin/php83 /var/services/web_packages/owncloud/occ upgrade
  sudo -u sc-owncloud /usr/local/bin/php83 /var/services/web_packages/owncloud/occ maintenance:repair

See the troubleshooting section of the upstream manual upgrade guide.

Option 2 - roll back to 10.16.3
-------------------------------
1. Copy the backup above somewhere safe: uninstalling the package removes
   /var/packages/owncloud (including its var/backup folder).
2. Uninstall ownCloud 11.0.1 from Package Center, keeping the data share.
3. Install owncloud 10.16.3-25 and choose to restore from a backup; select
   the backup file above. The package restores the configuration, apps and
   database, and re-applies the PHP 7.4 WebStation profile.
4. If you customized .htaccess or .user.ini, re-apply them from configs/root
   inside the backup archive.
